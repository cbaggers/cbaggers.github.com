Hey folks,

For the last day or so, I've been working on a command-line tool for creating TaleSpire content-packs. This is a community-requested feature, but it has the additional benefit of helping folks like TitanCraft who want to export from their pipelines directly to TaleSpire packs. It's basically a command-line complement to TaleWeaverLite.

It currently only supports creatures, but when we add support for community-made tiles and props, we'll expand this tool to support those too.

The plan is to ship the tool in a subdirectory of TaleSpire, with versions built for Linux, Mac, and Windows from the get-go.

Other than that, my work on shadows is going ok so far. I'm hoping I don't find any horrors as I get deeper into it.

Peace.
